# Playing

## Modes
- **Online:** pick a variant, your colour and a time control, then **Create Game**. Send the six-character code (or the link) to your opponent; the game starts when they join. If you close the page, reload it or open the game from the **Rejoin** list to get your seat back. No account needed.
- **Local Match:** you play both sides on one screen. By default the view flips to the player to move after each submit (you can turn this off in Settings).

## Time controls
No Clock, Short (10+3/L), Medium (20+5/L) or Long (40+8/L). The first number is your main time in minutes. At the start of each turn you also get a delay of the second number of seconds **per active timeline**, shown as "+N". The delay runs first, and unused delay is lost. Run out of main time and you lose.

## Screen
- **Top:** Undo Move (or Deselect while a piece is selected) and Submit Moves.
- **Right edge, from the top:**
  - the `*` menu (leave, resign, offer a draw, copy the code, export the game as 5D PGN, settings)
  - the time-travel animation button
  - History View and Parallel View (3D views; click the green tab again to go back)
  - Flip Persp.
  - the board-cycle button
- **Bottom left:** whose turn it is. **Top left:** the clocks, in timed games.

## Controls
| Action | Input |
|---|---|
| Select / move | Left click |
| Put the piece down | Right click or Esc |
| Undo | Backspace, Z or Ctrl/Cmd+Z |
| Submit | Enter or F |
| Cycle playable boards | Tab |
| Pan | Drag, WASD or arrow keys |
| Zoom | Scroll, pinch, E / Q |
| History View / Parallel View / Flip | T / Y / U |
| Arm the time-travel animation | I |
| Game menu | Esc (with nothing selected) |
