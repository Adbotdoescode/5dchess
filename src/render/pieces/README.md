# Piece art

## Standard pieces (cburnett.ts)

The standard pieces (K, Q, R, B, N, P) are embedded SVG strings with the XML prolog/DOCTYPE stripped; paths are unchanged.

## Fairy pieces (fairy.ts)

Drawn for this project in the same style (45x45 viewBox, 1.5 px strokes):

| Letter | Piece | Design |
|---|---|---|
| U | Unicorn | knight outline + spiral horn and mane lines |
| D | Dragon | knight outline + dorsal spikes, two horns, forked tongue |
| S | Princess (rook + bishop) | rook base, tower with a bishop's mitre, slit and ball |
| W | Brawn | broad-shouldered pawn |
| C | Common king (non-royal) | king with a ring instead of the cross |
| Y | Royal queen | queen with the king's cross on the centre point |

No art was taken from other implementations of this game.
