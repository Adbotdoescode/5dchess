## Fairy pieces (fairy.ts)

Drawn for this project in the same style (45x45 viewBox, 1.5 px strokes):

| Letter | Piece | Design |
|---|---|---|
| U | Unicorn | cburnett knight outline + spiral horn and mane lines |
| D | Dragon | cburnett knight outline + dorsal spikes, two horns, forked tongue |
| S | Princess (rook + bishop) | cburnett rook base, tower with a bishop's mitre, slit and ball |
| W | Brawn | original: broad-shouldered pawn |
| C | Common king (non-royal) | cburnett king with a ring instead of the cross |
| Y | Royal queen | cburnett queen with the king's cross on the centre point |

The parts derived from cburnett paths are covered by the BSD notice above.

No art was taken from the AGPL reference projects (chess-in-5d, 5d-chess-renderer).
